# Data Structures in Java

Collection of data structure and algorithm projects completed for CS 3305.

## Projects

### Reachability Matrix
Graph analysis using adjacency matrices and matrix powers to determine reachability, paths, cycles, and graph statistics.

### Hash Functions
Comparison of multiple hashing techniques including:
- Linear Probing
- Quadratic Probing
- Double Hashing
- Custom Hash Function

### Heap and Priority Queue
Implementation of:
- Generic Heap
- Heap Sort
- Priority Queue using Heap

### Radix Sort
Queue-based radix sort implementation using a custom generic queue.
